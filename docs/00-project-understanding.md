# プロジェクト理解

## ひとことで言うと

既存のAppSheetアプリを参考にしながら、工事完了報告書、日報、請求、月次集計を扱う「オシゴトアプリ」を新しく作る。

## 既存アプリで扱っている業務

DriveとGoogle Sheetsの調査から、既存アプリは主に次の業務を扱っていると推定する。

- 工事完了報告書の入力
- 完了報告書PDFの作成とDrive保存
- 駐車場領収書画像の保存
- 日報、作業金、残業代、駐車場代、高速代の記録
- 溶剤や立替などのマイナス請求
- 月次集計
- 請求書と月次作業金一覧の生成

## 新アプリで大事にすること

- スマホで現場入力しやすいこと
- PCで確認、修正、集計しやすいこと
- PDFや帳票の出力が安定していること
- データの置き場所と意味が分かりやすいこと
- 将来、項目追加や単価変更がしやすいこと
- GitHubで履歴管理できること

## まだ確定していないこと

- AppSheet側の画面、アクション、自動化、式の詳細
- 新アプリをWebアプリにするか、AppSheet再構築にするか
- Google Sheetsをそのまま主データにするか、専用データベースへ移すか
- PDF生成をGoogleテンプレで続けるか、アプリ側で生成するか
- ユーザー権限が本人だけか、複数人で使うか

## 作業の基本方針

不明点がある場合は、実装で勝手に決めず、確認してから進める。

ただし、調査結果から明らかに安全な作業、たとえばドキュメント化やローカルGitの初期化は進めてよい。
