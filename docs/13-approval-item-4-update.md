# Approval Item 4 Update

Date: 2026-07-22
Status: Waiting for file review

## 更新対象

Phase 2承認チェックリストの4番を更新します。

## 旧4番

PDF/請求書の完全実装は、画面とデータの土台ができた後でよい。

## 新4番

工事完了報告書と丸産報告書だけは、初期MVPでPDF作成可能にする。

請求書、月次一覧表、その他のPDF生成は後続フェーズでよい。

## 理由

この2つの書類は、アプリの中心業務に直結しており、フォーム入力からPDF作成まで動かせる必要があるため。

また、書式変更が発生したため、旧AppSheetの項目をそのまま移植するのではなく、新しいPDF/Excel書式から入力項目を再確認する必要があります。

## 次に必要なファイル

- 新しい工事完了報告書のPDF
- 新しい工事完了報告書のExcel
- 新しい丸産報告書のPDF
- 新しい丸産報告書のExcel

## ファイル確認後の完了条件

- 工事完了報告書の入力項目一覧ができている
- 丸産報告書の入力項目一覧ができている
- 既存データとの対応表ができている
- ユーザーがフォーム入力項目を承認している
- その後、PDF作成をMVP範囲に入れて実装へ進める
