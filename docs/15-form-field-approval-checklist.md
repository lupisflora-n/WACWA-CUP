# 新フォーム項目の承認チェック

日付: 2026-07-22

状態: 2026-07-23回答済み

回答内容は `docs/16-approved-form-specification.md` に反映した。

## A. ファイルの対応

確認結果では、PDFのファイル名だけが入れ替わっているように見える。

推奨回答:

- [x] A1: その理解で正しい。内容を基準に進めてよい。
- [ ] A2: 違う。正しい対応を説明する。

PDF2ファイルは中身に合う正しい名前へ変更済み。

## B. 工事明細の数

新しい工事完了報告書には、工事内容・数量・備考の明細欄が3段ある。

回答:

- [x] 工事内容は1つの複数行入力欄にする。
- [x] ユーザーが入力した改行をPDFでも維持する。
- [x] 枠幅に合わせて自動折り返しする。
- [x] 数量は最初の行だけ「一式」を固定表示する。
- [x] 数量のフォームは作らない。
- [x] 備考3行は空欄固定とし、フォームを作らない。

## C. 金額の計算

新書式だけでは計算規則が分からないため、次を確認する。

- 合計は手入力か、自動計算か。
- 消費税率は通常10%でよいか。
- 合計額は `合計 + 消費税` でよいか。
- 駐車場代、高速代、材料代を合計に含めるか。

回答:

- [x] 合計は金額を手入力する。
- [x] 駐車場代、高速代、材料代は合計に含めない。
- [x] 消費税は合計の10%を初期値として自動計算する。
- [x] 消費税はフォームで手動編集できる。
- [x] 合計額は空欄固定とし、フォームを作らない。
- [ ] 消費税の1円未満を切り捨て、四捨五入、切り上げのどれにするか。

## D. 吹付塗装と特別材料

推奨:

- [x] 吹付塗装は「有・無」から選択する。
- [x] PDFでは選択した項目名に丸印を描画する。
- [x] 「有」の場合だけ詳細入力欄を表示する。
- [x] 吹付塗装の詳細は任意改行と自動折り返しに対応する。
- [x] 通常材料以外の材料内容は常に表示する。
- [x] 通常材料以外の材料内容も任意改行と自動折り返しに対応する。

## E. 丸産のAM/PM欄

回答:

- [x] E3: AMとPMはそれぞれ自由入力欄にする。
- [x] 作業内容は書式上の6枠に分ける。
- [x] 作業日は年、月、日をそれぞれ数値入力する。
- [x] 作業者は6人分の入力欄を作る。
- [x] 作業者1は利用者本人とし、初回設定後は固定する。

## F. 丸産の社名

PDF下部の「社名」に表示する正式名称を回答する。

回答:

`F: 株式会社ＴＲＣ`

## G. 連絡事項の分け方

回答:

- [x] 1つの複数行入力欄を作る。
- [x] 任意改行と自動折り返しに対応する。

## 回答方法

短く回答してよい。

例:

`A1、B1、Cは例の通り、D1/D2、E1、Fは株式会社○○、G2`

残る確認は、消費税の1円未満の端数処理とPDF生成方式の承認。
