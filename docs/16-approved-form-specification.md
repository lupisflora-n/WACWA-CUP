# 承認済みフォーム仕様

日付: 2026-07-23

状態: 承認済み（実装前仕様）

## 共通の文章入力仕様

複数行の文章を入力する欄は、すべて同じ規則で扱う。

- アプリでは複数行入力欄を使う。
- Enterによるユーザーの任意改行を保存する。
- PDFでもユーザー改行を同じ位置の強制改行として再現する。
- ユーザーが改行しなくても、PDFの枠幅に合わせて自動折り返しする。
- 日本語文字の実際の幅を測って折り返す。
- 枠の高さを超えそうな場合は、許容範囲内で文字サイズを縮小する。
- 最小文字サイズでも収まらない場合は、文字を切らずPDF作成を停止し、該当欄を画面で知らせる。
- PDF作成前に帳票プレビューを確認できるようにする。

これにより、文字が枠外へはみ出した状態のPDFを保存しない。

## 工事完了報告書

### 工事内容

- フォームは1つの複数行入力欄にする。
- ユーザー改行と自動折り返しをPDFへ反映する。
- 既存の `work2` から `work10` は、移行時に改行で連結して1つの値にする。

### 数量

- フォームは作らない。
- PDFの最初の行に「一式」を固定表示する。
- 2行目以降は空欄にする。

### 備考

- フォームは作らない。
- 3行とも空欄にする。

### 合計と消費税

- 合計は金額数値を手入力する。
- 駐車場代、高速代、材料代は合計に含めない。
- 消費税は `合計 × 10%` を初期値として自動計算する。
- 消費税欄は手入力で上書きできる。
- 合計を変更し、消費税を上書きしていない場合は自動再計算する。
- 合計額は空欄固定とし、フォームを作らない。
- 消費税の1円未満の端数は切り捨てる。

### 吹付塗装

- フォームでは「有」「無」のどちらかを選ぶ。
- 回数と完了状態の選択と同じ操作方式にする。
- PDFでは選択した項目名に丸印を描画する。
- 「有」を選んだ場合だけ詳細入力欄を表示する。
- 詳細入力欄は複数行、任意改行、自動折り返しに対応する。
- 「無」に変更した場合、入力済み詳細を削除する前に利用者へ確認する。

### 通常材料以外の材料内容

- 入力欄は常に表示する。
- 複数行、任意改行、自動折り返しに対応する。
- 未入力でも保存できる。

## 丸産報告書

### 提出日

- PDFを作成した日を初期値にする。
- 年、月、日を分けてPDFへ描画する。

### 作業日

- 年、西暦4桁の数値入力。
- 月、1から12の数値入力。
- 日、1から31の数値入力。
- 存在しない日付は保存できない。
- データベースには1つの日付として保存し、画面だけ3つの入力欄にする。

### AMとPM

- AMとPMにそれぞれ自由入力欄を作る。
- 時刻形式に限定せず、文字として入力できる。

### 作業内容

- 書式上の6枠を、AM側3枠とPM側3枠として扱う。
- アプリにも6つの入力欄を用意する。
- 入力順とPDFの出力位置を固定する。
- 各欄で枠幅に応じた自動折り返しを行う。

### 作業者

- 6人分の入力欄を用意する。
- 1人目はログイン利用者本人。
- 初回設定時に本人名を登録し、それ以降の新規報告へ自動入力する。
- 通常の報告フォームでは1人目を編集不可にする。
- 誤登録時は、設定画面から本人または管理者が明示的に再設定できるようにする。
- 2人目から6人目は作業者マスタから選択し、必要なら手入力も可能にする。

### 連絡事項・注意事項・明日の作業予定

- 1つの複数行入力欄にする。
- 任意改行と自動折り返しに対応する。

### 社名

- 「株式会社ＴＲＣ」を固定表示する。
- 通常利用者向けフォームには表示しない。

## PDF選択マーク

次の選択は、PDF上で選択項目名に丸印を描画する。

- 1回目・2回目・3回目
- 完了・未完
- 吹付塗装の有・無

文字の「〇」を別欄に置くだけではなく、項目名の位置に合わせて丸を描画する方式を採用する。

## 実装前に残る確認

消費税の計算結果に1円未満が出た場合の処理を、次から選ぶ。

- 切り捨て
- 四捨五入
- 切り上げ
