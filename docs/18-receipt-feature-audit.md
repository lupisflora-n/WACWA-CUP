# 既存領収書機能の確認結果

状態: 読み取り確認完了、改良仕様は実装前

## 今確認できたこと

- 入力データの領収書欄はGoogle Sheetsの `completion_reports` にある `parkingReceiptImage`。
- AppSheetのデータ設定では、`completion_reports` がGoogle Sheetsをデータ元として接続されている。
- 既存Apps Scriptは、AppSheetから渡された画像パスの `id=` または `/d/` を使ってDriveの画像ファイルを取得する。
- PDF化では、Googleスライド台紙上の `{{parkingReceiptImg}}` の図形を探し、その図形の左・上・幅・高さをそのまま貼り付け枠として `insertImage` している。
- 既存スクリプトには、領収書画像について白黒化、グレースケール化、トリミング、回転補正、台形補正、OCR、複数画像の結合は確認できない。
- 現行は「撮影または選択された画像を、既存の画像枠へそのまま貼る」仕組みであり、視認性向上の加工機能は未搭載と判断する。

## まだ確定できないこと

- AppSheetの端末上で、画像欄がカメラ撮影と端末内画像選択の両方を許可しているか。
- 画像の最大容量・解像度・圧縮設定。
- 1件の報告に領収書を1枚だけ添付する設計か、複数枚が必要か。
- 元画像を必ず保存し、加工後画像も別に保存するか。

## 新アプリでの検討案

1. カメラ撮影または端末内画像選択。
2. 撮影後プレビュー。
3. 手動トリミング、回転、白黒化または高コントラスト化。
4. 元画像を残したまま、PDF用の加工画像を生成。
5. PDFでは加工画像を設定された領収書枠へ収める。
6. 領収書枠の位置・幅・高さを設定ファイルまたは管理画面から変更できるようにする。

加工は元画像を壊さない方式を基本とする。タグ位置、枠サイズ、文字設定もコード本体から分離し、ユーザーが後から微調整できる構造にする。

## 実装していない範囲

この確認では、AppSheet設定、Google Sheets、Apps Script、Driveファイル、PDF台紙を変更していない。新アプリ側の撮影・加工・トリミングもまだ実装していない。
