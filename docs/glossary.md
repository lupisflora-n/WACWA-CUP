# 用語集

## AppSheet

Google Sheetsなどをもとに、ノーコードでアプリを作れるサービス。

## Google Sheets

Googleの表計算ソフト。ExcelのGoogle版と考えると分かりやすい。

## テーブル

データを入れる表のこと。
たとえば「完了報告書」テーブル、「日報」テーブル、「溶剤マスタ」テーブルのように使う。

## カラム

表の列のこと。
たとえば「作業日」「現場名」「作業金」など。

## レコード

表の1行分のデータ。
たとえば1件の完了報告書、1日の作業日報など。

## マスタ

何度も使う固定情報をまとめた表。
たとえば溶剤名と単価、請求先、作業者名など。

## PWA

ブラウザで使うWebアプリだが、スマホのホーム画面に追加してアプリのように使える方式。

## API

アプリ同士がデータをやり取りするための入口。
利用者が直接触る画面ではなく、裏側の連絡係のようなもの。

## PDF生成

入力されたデータを、印刷や送付に使えるPDFファイルに変換すること。

## テンプレート

帳票のひな形。
「ここに会社名を入れる」「ここに現場名を入れる」という穴埋め用の紙のようなもの。

## Git

変更履歴を記録する仕組み。
失敗したときに戻したり、いつ何を変えたか確認したりできる。

## GitHub

Gitの履歴をインターネット上で管理できるサービス。
共同開発やバックアップにも使える。

## リポジトリ

GitHub上のプロジェクト置き場。
今回の名前は `WACWA-CUP`。

## コミット

変更履歴の保存ポイント。
ゲームのセーブに近い。

## ブランチ

本線とは別に作業するための分岐。
試作や修正を安全に進めるために使う。
